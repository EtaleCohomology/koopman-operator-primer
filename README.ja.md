# クープマン作用素の入門デモ（Python）

非線形の動きを「測り方を増やして」線形に扱うクープマン作用素と、データから行列を当てる動的モード分解（DMD）を、答えが分かっている例で確かめるためのデモです。

## 収録ファイル

### `koopman_beginner_demo.py`（入門デモ）

非線形の動き x(t+1) = 0.9 x(t)、y(t+1) = 0.5 y(t) + 0.3 x(t)^2 を使います。

- 測り方が x, y の2つだけでは、線形回帰で次の値を当てられない
- 測り方に x^2 を加えて x, y, x^2 の3つにすると、動きが行列の掛け算でぴったり書ける
- 求めた行列の固有値は 0.9, 0.81, 0.5（答えと一致）

### `koopman_dmd_early_warning.py`（谷底からの戻りの速さ）

答えが分かっている地形 h(x, y) = (x^2 − 0.5)^2 + y^2 + a·x を下る流れを使います。

- 右の谷底の近くで観測したデータだけから、DMD（定数項を別に推定するアフィン版）で固有値を推定する
- 推定した固有値を、谷底の曲がり方から計算できる正解の値と比べる
- 地形の傾き a を大きくして谷底のまわりをなだらかにすると、固有値が1に近づき、戻りの半減期が延びることを確かめる（a = 0.544 付近で、右の谷底は峠と重なって消える）

## 動かし方

```bash
pip install numpy
python koopman_beginner_demo.py
python koopman_dmd_early_warning.py
```

確認した環境：Python 3.12.3、NumPy 2.4.4。乱数の種を固定しているので、同じ結果が出ます。

## 使うときの注意

- これは、答えが分かっている作り物のデータでの確認です。経営データで同じように正確に読み取れることを保証するものではありません。
- 固有値が1に近づくことは、「安定していた状態が揺らいでいるかもしれない」という候補のサインで、それだけで転換を断定はできません。
- DMDの固有値が「谷底への戻りの速さ」を表すのは、安定した谷底の近くのデータで、その近くの動きを近似した場合です。
